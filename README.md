# Expense Tracking Module 💰

A simple and efficient .NET C# console application designed to help users track and manage their daily expenses. Created as part of **Lab 3 of sem 5 .net subject**.

---

## 🚀 Features
* **Expense Management:** Add, view, and categorize your daily expenses.
* **Console Interface:** Lightweight, fast, and easy-to-use user interface.
* **Structured Codebase:** Built using object-oriented principles in .NET C#.

---

## 🛠️ Built With
* **Language:** C# (.NET Framework)
* **IDE:** Visual Studio / VS Code

---

```

ExpenseTrackingModule/
```

## 🏁 Getting Started

### Prerequisites
* [.NET SDK](https://dotnet.microsoft.com/download) installed on your machine.
* Visual Studio or VS Code.

### How to Run
1. **Clone the repository:**
   ```bash
   git clone [https://github.com/ius-sharma/ExpenseTrackingModule.git](https://github.com/ius-sharma/ExpenseTrackingModule.git)

```

2. **Navigate to the project directory:**
```bash
cd ExpenseTrackingModule

```


3. **Run the application:**
* Open `ExpenseTrackingModule.sln` in Visual Studio and press `F5`, or
* Run using .NET CLI:
```bash
dotnet run

```
