# Expense Tracking Module 💰

A simple and efficient .NET C# console application designed to help users track and manage their daily expenses. Created as part of **Lab 3 of our .net**.

---

## 🚀 Features
* **Expense Management:** Add, view, and categorize your daily expenses.
* **Console Interface:** Lightweight, fast, and easy-to-use user interface.
* **Structured Codebase:** Built using object-oriented principles in .NET C#.

---

## 🛠️ Built With
* **Language:** C# (.NET Framework)
* **IDE:** Visual Studio / VS Code
